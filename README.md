## Product Category Classification Using Random Forest
A machine learning project for classifying products into predefined categories using a Random Forest Classifier based on product attributes such as price, rating, inventory, discount, and purchase quantity.

### Overview
This project aims to build a classification model that predicts the category of a product based on several numerical attributes.

The product categories in the dataset are:
```
- Accessories
- Electronics
- Clothing
```
The project covers data preprocessing, exploratory data analysis, feature selection, model training, and evaluation.

### Methodology

The workflow consists of the following steps:
```
Data loading and inspection
Removal of the ID column
Missing value handling
Duplicate data checking
Exploratory data analysis and visualization
Feature and target selection
Train-test splitting
Random Forest model training
Model evaluation using accuracy, confusion matrix, and classification report
```
